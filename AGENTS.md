# NE Oakville school reconstruction
All files, dependency installation, builds, tests and publishing commands run on MaxCompute11 via SSH. Do not edit a local checkout. User requests low-effort parallel agents. Do not run workloads on login node.
Source images: public/references/*.jpg. Photos 7,8,9 = same L1; 1,5 = same L3; 4=L2;10=L0;3=site;6=north/south elevations;2=street perspective.
Accuracy: photos are undimensioned and distorted. All metric dimensions are inferred. Never claim survey/BIM accuracy. Label evidence as traced, inferred, unresolved. Preserve room relationships, roof/void areas, childcare below southwest gym wing.
Data contract: src/data/level0.json ... level3.json each {level:0, elevation:-4.2, label:string, source:string, rooms:[{id:string,name:string,category:string,polygon:[[x,z],...],confidence:"traced"|"inferred",notes:string,height?:number}],circulation:[{id:string,name:string,polygon:[[x,z],...]}],voids:[{id:string,name:string,polygon:[[x,z],...]}]}. Coordinates use common Photo8 image pixel grid (x right, z down). Renderer converts x=(x-640)*0.14 and z=(z-480)*0.14. 0.14 m/pixel is assumed visual calibration, not measured. Y up. Heights L0=-4.2,L1=0,L2=4.2,L3=8.4. Roof typical12.6. Tall spaces have height8.1 when supported.
